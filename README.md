# Living Archive Curriculum

A hybrid program for building retrieval-based cultural heritage archives: the method behind the Du Bois, Ida B. Wells and Garvey living archives, taught.

**Visit:** [living-archive-curriculum.vercel.app](https://living-archive-curriculum.vercel.app)

## How it's organized

Pick a pathway, then a length, then work through its units, each available in more than one format, so the same material fits a workshop, a short course or a full program.

## How it's built

React, TypeScript and Vite, deployed on Vercel.

**Related:** [living-archives](https://github.com/ShdwSpde/living-archives), the archives this curriculum teaches you to build.
