# Pathway 2: Archive Builder
## Curriculum Overview for Funders

### Who This Is For
Librarians, archivists, digital humanists, and researchers who want to deploy a working living archive using guided tools — without writing code from scratch.

### What Participants Learn
By the end of this program, participants can:
- Set up and configure a Supabase database for vector search
- Download, clean, and organize a public-domain corpus
- Run provided ingestion scripts to embed and store a corpus
- Test and refine RAG query quality
- Deploy a live archive to Vercel and share it publicly
- Document and replicate the process for a second figure

### Available Formats

| Format | Sessions | Weekly Commitment | Deliverable |
|--------|----------|------------------|-------------|
| **2-week intensive** | 6 sessions | 3 × 75 min/week | Cleaned corpus + configured Supabase account |
| **4-week program** | 12 sessions | 3 × 75 min/week | Working archive with functional RAG queries |
| **6-week program** | 18 sessions | 3 × 75 min/week | Two deployed archives + replication guide |

### Session Format
Each session includes:
- **Async web materials** (30–45 min): readings, setup instructions, pre-work
- **Virtual lesson** (75 min): live online — screen share walkthroughs, troubleshooting, breakouts
- **In-person lesson** (75 min): hands-on computer lab — guided build, pair work

### Technical Prerequisites
- Comfort with a web browser and basic file management
- Willingness to run terminal commands by following step-by-step instructions
- A laptop with internet access

### What "Guided" Means
Participants use pre-written scripts from the Du Bois archive as starting points. They configure them for their figure — changing filenames, title mappings, and metadata — but do not write logic from scratch.

### Sample Learning Arc (4-week)
- **Week 1:** Choose a figure. Download corpus from Internet Archive. Set up Supabase. Run prep scripts.
- **Week 2:** Understand embedding. Run ingestion pipeline. Verify data quality.
- **Week 3:** Configure metadata. Test queries. Debug quality issues.
- **Week 4:** RAG pipeline review. Pitfalls and fixes. First live queries.
