# Pathway 3: Archive Developer
## Curriculum Overview for Funders

### Who This Is For
Researchers with a coding background (any language), developers embedded in humanities departments, or scholar-practitioner teams with a technical member who will build the archive.

### What Participants Learn
By the end of this program, participants can:
- Write a custom text chunking and chapter detection script in TypeScript
- Configure pgvector with HNSW indexing in Supabase
- Build a batch embedding pipeline with rate limiting and resume support
- Write SQL RPC functions for similarity search
- Implement a full RAG query pipeline with source attribution
- Customize the React frontend for a new historical figure
- Deploy to Vercel with environment variable management
- Replicate the entire process for a second archive

### Available Formats

| Format | Sessions | Weekly Commitment | Deliverable |
|--------|----------|------------------|-------------|
| **2-week intensive** | 6 sessions | 3 × 75 min/week | Ingested corpus in Supabase with HNSW index |
| **4-week program** | 12 sessions | 3 × 75 min/week | Full backend with tested RAG query pipeline |
| **6-week program** | 18 sessions | 3 × 75 min/week | Production-ready archive with custom React UI |

### Technical Prerequisites
- Familiarity with at least one programming language
- Comfort with the command line / terminal
- Basic understanding of web APIs (what a request/response is)
- Node.js and npm installed

### Sample Learning Arc (4-week)
- **Week 1:** Architecture deep-dive. Choose figure. Write chunking script. Set up pgvector. Run embeddings.
- **Week 2:** Schema design. HNSW index. RPC functions. Ingestion pipeline with backoff.
- **Week 3:** RAG query implementation. Prompt engineering. Source attribution. Quality testing.
- **Week 4:** Pitfall diagnosis. Performance optimization. Cost analysis. Production readiness.
