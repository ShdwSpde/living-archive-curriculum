# Pathway Comparison for Funders

| | Pathway 1: Advocate | Pathway 2: Builder | Pathway 3: Developer |
|--|---------------------|-------------------|---------------------|
| **Best for** | Administrators, curators, grant writers | Librarians, archivists, digital humanists | Researchers with coding background |
| **Technical depth** | None | Low-code (guided scripts) | Full implementation |
| **By end of 2 weeks** | Corpus proposal written | Corpus cleaned + DB configured | Corpus ingested in Supabase |
| **By end of 4 weeks** | Full proposal + pitch deck | Working archive live | Full RAG backend tested |
| **By end of 6 weeks** | Grant-ready brief + budget | Two deployed archives | Production archive + custom UI |
| **Room setup** | Seminar room or cluster tables | Computer lab required | Computer lab required |
| **Facilitator background** | Digital humanities or library science | Digital humanities + basic tech | Software development background |
| **Cost to run** | Lowest | Moderate | Highest |
| **Licensing / replication** | Yes — institutions can retrain facilitators | Yes | Yes |

## Recommended Pairings

- **Single-institution cohort:** Pathway 2 (4-week) — staff build their first archive together, share one figure
- **Consortium / multi-institution:** Pathway 1 (6-week) for leadership + Pathway 3 (6-week) for technical staff in parallel
- **Faculty research support:** Pathway 3 (4-week) — researcher + librarian pair, each takes a figure
- **Grant proposal development:** Pathway 1 (2-week) — rapid scope for an upcoming grant deadline
