# Pathway 1: Archive Advocate
## Curriculum Overview for Funders

### Who This Is For
Curators, administrators, grant writers, and humanities faculty who need to understand, evaluate, commission, and steward living archive projects — without writing any code themselves.

### What Participants Learn
By the end of this program, participants can:
- Explain how RAG-based living archives work to non-technical and funding audiences
- Identify a historical figure with a suitable corpus and write a formal archive proposal
- Evaluate technical vendors and developers for an archive project
- Build a sustainability plan with realistic cost projections
- Present an archive initiative to institutional leadership or funders

### Available Formats

| Format | Sessions | Weekly Commitment | Deliverable |
|--------|----------|------------------|-------------|
| **2-week intensive** | 6 sessions | 3 × 75 min/week | Annotated corpus proposal |
| **4-week program** | 12 sessions | 3 × 75 min/week | Full archive proposal + funder pitch deck |
| **6-week program** | 18 sessions | 3 × 75 min/week | Grant-ready archive brief with budget |

### Session Format
Each session includes:
- **Async web materials** (30–45 min): readings, reflection questions, prep task
- **Virtual lesson** (75 min): live online — slides, screen share, breakout groups
- **In-person lesson** (75 min): workshop format — activities, facilitation, group synthesis

### No Technical Prerequisites
Participants need no coding background. Sessions use the living archive itself as a demonstration tool, not a build environment.

### Sample Learning Arc (4-week)
- **Week 1:** What is a living archive? Choosing a figure. Corpus research.
- **Week 2:** How text becomes searchable. What AI is (and isn't) doing. Database concepts without the database.
- **Week 3:** Metadata strategy. Understanding RAG queries. Briefing technical teams. Common failure modes.
- **Week 4:** Proposal writing workshop. Funder pitch preparation. Final presentations.
